# Информация о данных (Dataset)

## Структура папки `data/`

```
data/
├── videos/                 # Исходные видеофайлы, загруженные с Яндекс.Диска
├── frames/                 # Извлечённые кадры из видео (каждый 30-й кадр)
├── all_frames_keep/        # Уникальные кадры после удаления дубликатов
├── data_to_augment/        # Аннотированные изображения с bounding box (формат YOLO)
├── augmented/              # Аугментированные изображения и соответствующие метки
├── dataset/                # Итоговое разбиение данных на train/val/test
│   ├── images/
│   │   ├── train/
│   │   ├── val/
│   │   └── test/
│   └── labels/
│       ├── train/
│       ├── val/
│       └── test/
└── predicted_videos/       # Результаты предсказаний модели на исходных видео
```

---

## Описание этапов подготовки данных

1. **Видео**: исходные ролики ресторанных блюд в формате `.mov` находятся в папке `data/videos`.

2. **Извлечение кадров**: с помощью скрипта `src/extract_video_frames.py` из каждого видео извлекаются кадры (например, каждый 30-й), которые сохраняются в `data/frames/<название_видео>`.

3. **Удаление дубликатов**: с помощью `src/remove_duplicated_in_all_folders.py` удаляются визуально похожие кадры, что позволяет уменьшить избыточность данных.

4. **Объединение кадров**: скрипт `src/all_frames.py` собирает уникальные кадры в общую папку `data/all_frames_keep` для дальнейшей обработки.

5. **Аннотация**: изображения размечаются вручную через [MakeSense.ai](https://www.makesense.ai) в формате YOLO (bounding boxes + классы). Аннотации и изображения находятся в `data/data_to_augment`.

6. **Аугментация**: с помощью `Albumentations` и скрипта `src/augment_yolo_dataset.py` создаётся по несколько новых версий каждого изображения, чтобы увеличить разнообразие обучающей выборки. Результаты сохраняются в `data/augmented`.

7. **Разбиение на выборки**: с помощью `src/data_splitting.py` набор данных делится на тренировочный (70%), валидационный (20%) и тестовый (10%) поднаборы, которые лежат в папке `data/dataset`.

---

## Формат аннотаций

* Каждое изображение сопровождается `.txt` файлом с аннотациями в формате YOLO:

```
<class_id> <x_center> <y_center> <width> <height>
```

* Координаты нормализованы в диапазоне \[0,1].

## Конфигурация датасета

Для обучения используется файл `food_dataset.yaml`:

```yaml
path: data/dataset
train: images/train
val: images/val
test: images/test
nc: 8
names:
  0: daikon_salad
  1: greek_salad
  2: shashlik
  3: wrap
  4: green_tea
  5: Borscht
  6: cheese_soup
  7: fondue
```

## Примечания

* В папке `data/predicted_videos` хранятся результаты предсказаний модели на исходных видео с визуализацией bounding boxes.
* Видео в формате `.avi`, кадры с разметкой по классам.
* Размер датасета относительно небольшой, поэтому исходные видео исключены из репозитория, но доступны по ссылке на Яндекс.Диск (указать ссылку).
